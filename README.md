# GasTrack

Aplicativo Android para registrar ciclos de uso de botijao de gas, entender o historico e estimar quando uma nova troca provavelmente se aproxima.

GasTrack e apenas o codinome de desenvolvimento.

Consulte:
- PROJECT.md
- ARCHITECTURE.md
- DECISIONS.md
- CHECKPOINT.md

Estado (2026-10-10): aplicativo em desenvolvimento. Hoje existe apenas o dominio de datas e de ciclos (testado); nao ha interface, banco, notificacoes nem build Android.

Testes: `npm test`, `npm run test:tz`, `npm run typecheck` (Node 22; sem dependencias de runtime). Ver CHECKPOINT.md.
