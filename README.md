# GasTrack

**Acompanhe o consumo do seu botijão de gás e tenha uma previsão de quando será a próxima troca.**

O GasTrack ajuda você a registrar cada troca de botijão, acompanhar quanto tempo ele dura e consultar seu histórico de consumo. Com essas informações, o aplicativo apresenta estimativas para ajudar no planejamento da próxima substituição.

## O que você pode fazer

- **Registrar trocas:** marque quando um novo botijão começa a ser utilizado.
- **Acompanhar o consumo:** veja há quantos dias o botijão atual está em uso.
- **Consultar o histórico:** confira a duração dos ciclos anteriores.
- **Visualizar estatísticas:** entenda melhor seus padrões de consumo.
- **Consultar previsões:** veja estimativas de quando o gás poderá acabar.
- **Personalizar o aplicativo:** escolha entre tema claro, escuro ou o tema do sistema, além das opções de idioma e animações.

## Disponibilidade

O GasTrack foi desenvolvido para Android. As versões para instalação serão divulgadas na seção [Releases](https://github.com/AvalonPhoenix486/GasTrack/releases) deste repositório.
